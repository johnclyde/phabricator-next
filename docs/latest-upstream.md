## API and CLI inventory boundary

Static inspection of literal `getAPIMethodName()` returns in `src/applications` finds **201** names in the 2021 tree and **186** in the active tree. This is a reproducible source count, not a claim that every method is enabled, public, stable, or suitable for agents. Inspect each method's availability, authentication, policy, constraints, attachments, cursor format and errors before implementing compatibility.

- Added: `harbormaster.build.edit`, `harbormaster.buildable.edit`.
- Removed: `feed.publish`, `owners.query`, `phragment.getpatch`, `phragment.queryfragments`, `releeph.getbranches`, `releeph.querybranches`, `releeph.queryproducts`, `releeph.queryrequests`, `releeph.request`, `releephwork.canpush`, `releephwork.getauthorinfo`, `releephwork.getbranch`, `releephwork.getbranchcommitmessage`, `releephwork.getcommitmessage`, `releephwork.nextrequest`, `releephwork.record`, `releephwork.recordpickstatus`.
- Relevant current foundations: `user.search`, `user.edit`, `user.whoami`, `auth.logout`; `maniphest.edit`, `maniphest.search`, `maniphest.status.search`, `maniphest.priority.search`; `project.edit`, `project.search`, `project.column.search`; `phriction.create`, `phriction.edit`, `phriction.info`, `phriction.history`, `phriction.document.search`, `phriction.content.search`; `transaction.search`.

Static literal `getWorkflowName()` returns in latest Arcanist enumerate 38 names across the old and newer workflow framework: `alias`, `amend`, `anoid`, `bookmarks`, `branches`, `browse`, `call-conduit`, `close-revision`, `commit`, `cover`, `diff`, `download`, `exec`, `export`, `get-config`, `help`, `inspect`, `install-certificate`, `land`, `liberate`, `lint`, `linters`, `list`, `look`, `paste`, `patch`, `prompts`, `set-config`, `shell-complete`, `tasks`, `todo`, `unit`, `upgrade`, `upload`, `version`, `weld`, `which`, `work`. This is a discovery list, not a promise that every workflow is exposed by the same binary. Command names and a modern API are insufficient to establish compatibility with Git/Hg/SVN working-copy semantics, lint/test protocols, configuration or extension loading.
